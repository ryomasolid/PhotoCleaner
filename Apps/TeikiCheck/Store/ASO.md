## 説明文（最大4000字）
```
その定期、買った方がお得？都度払いのままがお得？——迷いをスッキリ解消。

定期チェックは、通勤・通学の定期券を「買うべきか」を数字で判定するシンプルな計算アプリです。片道の普通運賃と定期代を入力するだけで、何往復で元が取れるか、今の通勤ペースで得か損かが一目でわかります。

■ こんな人に
・定期を買うか、都度払い（IC・きっぷ）のままか迷っている
・在宅勤務やシフト勤務で、月の通勤日数が読めない
・引っ越し・転職・進学で通勤ルートが変わった
・定期区間内のお出かけも多く、実はもっとお得かも？と思っている

■ 主な機能
・片道運賃・定期代・期間（1／3／6ヶ月）・月の通勤日数から損益を自動計算
・「元が取れる往復回数」を大きく表示
・「買うべき／トントン／都度払いがお得」をわかりやすく判定
・定期区間内の追加利用（途中下車での買い物・区間内の駅での用事など）を元取りに加算
・計算した区間を保存して、後から見返せる履歴機能

■ ここがポイント
定期のいちばんの魅力は「区間内が乗り放題」なこと。通勤だけでは元が取れなくても、休日のお出かけや途中下車を足すと元が取れるケースは多くあります。定期チェックは、その「区間内で浮く運賃」も計算に入れて、本当にお得かを判定します。

■ 安心・プライバシー
・入力したデータはすべて端末内に保存され、外部サーバーへ送信されません
・アカウント登録は不要です

※ 一部の快適機能・広告非表示は Pro（買い切り）で解放されます。

※ 本アプリは運賃の目安を計算するツールです。実際の運賃・定期代は各鉄道・バス事業者の公式情報をご確認ください。
```

## スクリーンショット構成（6.7" と 6.5"/5.5" を用意）
1. フック: 「その定期、元が取れる？」＋ 判定バッジ（買うべき！）のイメージ
2. 入力画面（片道運賃・定期代・期間・通勤日数）
3. 結果カード（元が取れる往復回数を大きく／損益額）
4. 定期区間内の追加利用を足すと黒字化する例
5. 履歴（保存した区間の一覧）
6. Pro 紹介（広告非表示）

## メモ
- 競合は各種「交通費・定期計算」アプリ。差別化＝「区間内利用の加算」と「買う/買わないの判定バッジ」をシンプルに前面へ。
- ローカライズはまず日本語。英語も用意すると幅が広がる（通勤定期＝commuter pass）。
